# 按键助手 UI 原型

这是一个使用 PySide6 制作的 Windows 多窗口按键工具。程序会自动发现标题包含“天龙八部”或“TLBB”的顶层窗口，并按左侧顺序应用独立配置。

## 运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

启动目标程序后，匹配窗口会自动出现在左侧列表。长按列表项约 350 毫秒后拖动，可以交换实际窗口的位置；配置始终属于固定位置，因此交换后会立即把窗口1配置应用到新的第一个窗口。

点击“启动”后，程序使用 Win32 `PostMessageW` 按各规则的间隔向后台窗口发送按键，不会主动抢占前台焦点。支持功能键、字母、数字、方向键以及 Ctrl、Alt、Shift 组合键。使用 DirectInput 或 Raw Input 的游戏可能不会响应普通窗口消息。

自动补气血和死亡回点目前只保存页面配置，尚未实现状态识别、死亡检测和寻路。

## 创建同名测试窗口

使用下面的命令创建指定数量的真实顶层窗口：

```powershell
python create_window_test.py 5
```

这些窗口的系统标题都严格为 `TLBB_天龙八部`，编号只显示在窗口内容中。每个窗口可以单独关闭，最后一个窗口关闭后测试程序退出。数量范围由 `config.toml` 控制。

按键助手会自动枚举并绑定这些测试窗口。测试窗口内容会显示最近收到的按键，适合验证后台投递。

## 配置文件

项目业务参数集中保存在脚本目录下的 `config.toml`，包括按键间隔、补给阈值、坐标范围、窗口扫描、调度频率和测试窗口参数。`[[game.windows]]` 的数组顺序就是窗口1、窗口2等固定配置槽。

页面中的规则、开关、阈值和坐标会在修改后自动防抖保存。写入使用同目录临时文件和原子替换；窗口句柄及当前拖动顺序不会保存，程序重启后重新按系统枚举顺序绑定。

`config.toml` 是必需文件。文件缺失、语法错误、字段类型错误或取值越界时，程序会在终端显示具体错误并退出，不会静默使用备用值。
